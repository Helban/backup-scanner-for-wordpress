      Scan log

        Code that WordPress loads by itself

        WordPress loads all of this by itself, with nothing to switch on in wp-admin. On every page view it runs wp-config.php, .maintenance, the mu-plugins and some of the drop-ins. The other drop-ins run in a situation of their own, such as a database WordPress cannot reach, and a copy started on a new machine stays in that situation until its database is connected. From wp-content/languages WordPress runs the file named after the site's language code (pl_PL.php, for example) on every page view, and it loads the translation files whenever it needs their texts. Translation files that hold nothing but texts are not listed. A wp-config.php is listed from the site's folder and from the one above it, the two places WordPress looks for it. Read all of it, whatever the findings say.
